# Changelog

All notable changes to `markdown-docx-compiler` will be documented in this
file.

The format is intentionally simple and release-oriented: each version groups
the user-visible changes that matter for adoption, compatibility, and release
notes.

## Unreleased

- No unreleased changes yet.

## 0.1.0

Initial public release.

Highlights:

- AI-native, agent-friendly markdown to DOCX compiler with a noun-verb CLI
- Sidecar-driven styling system that keeps source markdown readable
- Google-Docs-friendly DOCX output intended for final human adjustment
- Example documents covering business, technical, and editorial workflows
- Ordered list rendering with clean restarts and hierarchical numbering support
